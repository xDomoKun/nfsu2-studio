# UNDERGROUND STUDIO

**A modern savegame editor for Need for Speed Underground 2.**

Underground Studio is an unofficial savegame editing tool for *Need for Speed: Underground 2* (2004). It provides a convenient way to customize your game progress, manage vehicles, explore hidden content, and experiment with cars that are normally unavailable to players.

The project focuses on editing savegame data without modifying the original game installation.

> 🚧 **Work in Progress**
>
> Underground Studio is actively being developed. Some advanced features, especially career-mode support for traffic vehicles, are still experimental.

## Features

### Savegame Editor
- Edit supported NFS Underground 2 savegame data
- Modify career-related values and money
- Manage garage and vehicle configurations
- Work with vehicle performance and Dyno settings
- Export modified savegames for use in the game

### Playable Traffic Cars

One of Underground Studio's main goals is to make the game's original traffic vehicles accessible through savegame editing.

- Access normally unavailable traffic vehicles
- Add traffic vehicle configurations to supported savegames
- Use verified configurations in **My Cars / Quick Race**
- Experiment with vehicle configurations without replacing original game assets

### Performance Tuning

Underground Studio is being extended to support performance customization for traffic cars.

Development includes:

- Performance part configurations
- Unique performance upgrades
- Dyno tuning data
- Applying performance settings to traffic vehicle configurations

Support for these features is still being expanded and tested.

### Career Mode Support

Traffic cars currently work in the My Cars / Quick Race environment when using compatible savegame configurations.

However, career mode handles vehicle ownership, purchases, unlocks, and garage data differently.

**Current status:**
- Traffic vehicles can appear in the career garage
- Driving them in career mode is not yet confirmed to work
- Additional career-related vehicle data is being investigated
- Full career-mode compatibility remains an experimental goal

## Design

Underground Studio takes visual inspiration from the original *Need for Speed Underground 2* interface.

The editor emphasizes:

- Dark interface elements
- Green highlights and selection effects
- Game-inspired buttons and icons
- Compact controls
- Minimal unnecessary text

The goal is to create a functional editor that feels connected to the original game.

## Getting Started

1. Create a backup of your original savegame.
2. Open Underground Studio.
3. Load a supported NFS Underground 2 savegame.
4. Make the desired changes.
5. Export your modified savegame.
6. Test the result in-game.

**Important:** Always keep an untouched backup. Experimental modifications may cause unexpected behavior or savegame incompatibilities.

## Project Philosophy

**Savegame editing first.**

Underground Studio aims to unlock new possibilities within NFS Underground 2 using savegame modifications rather than requiring replacements of original game files.

The project is also an exploration of how the game's vehicle, garage, performance, and career systems store and interpret data.

## Compatibility

- **Game:** Need for Speed: Underground 2 (PC)
- **Method:** Savegame editing
- **Game file modifications:** Not required for the verified traffic-car tests
- **Status:** Active development

Compatibility may vary depending on the savegame and the feature being used.
