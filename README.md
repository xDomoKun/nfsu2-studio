# NFSU2 Studio v1.7.15

**Browser Editor:**

**🎮 [NSFU2-Studio v1.7.15](https://xdomokun.github.io/nfsu2-studio/)**

---

**Major Update — What's New Since v1.0**

NFSU2 Studio has evolved from a basic savegame editor into a comprehensive vehicle, garage, and performance customization tool for **Need for Speed: Underground 2**.

Version 1.7.15 introduces expanded vehicle selection, improved Career and Arcade garage management, advanced performance tuning, new parts-unlocking functionality, and numerous interface improvements.

All modifications are performed through savegame editing, without changing the original game files.

---

## 🚗 Vehicle & Garage Management

- **46 selectable vehicles:** 31 regular cars and 15 traffic vehicles.
- **20 Arcade / My Cars slots** with individual vehicle assignments.
- **10 Career garage slots** with vehicle replacement and management.
- Added support for playable traffic vehicles in Arcade and Career Mode.
- Improved vehicle identification, templates, and garage compatibility.
- Added vehicle removal and safer replacement operations.
- Improved handling of vehicle IDs and mandatory Career garage slots.

**Testing:** Selected traffic vehicles have been successfully driven in both Arcade and Career Mode. The expanded vehicle selection system has passed technical tests across 920 slot combinations, although not every combination has been tested in-game.

## 🔓 NEW — Unlock All Parts

A new vehicle-specific unlocking feature has been introduced.

- Unlock supported customization and upgrade availability values for individual Career vehicles.
- Processes **420 part-unlock values** per selected vehicle.
- Designed to preserve existing installed parts and performance settings.
- Includes a progress indicator and **one-click Undo**.
- Successfully tested for savegame integrity and correct data modification.

**Status:** Technical verification completed. Full in-game shop compatibility is still being tested.

## ⚡ Performance Upgrades & Tuning

Significant improvements to vehicle performance customization:

- Expanded Performance Shop with **9 upgrade categories**.
- Stock, Street, Pro, and Extreme performance configurations.
- Support for Stage 3 and compatible Unique Upgrades.
- **MAX OUT** option for supported performance values.
- Advanced ECU, Turbo, and transmission tuning.
- Optional performance boosts for traffic vehicles.
- Ability to preserve original traffic-car performance.
- Improved handling of custom performance configurations.

**Testing:** Multiple traffic-car performance configurations have been successfully tested in-game, including improved acceleration. Some advanced handling modifications remain experimental.

## 🏁 Dyno Tuning Presets

Introduced automatic tuning presets for five race disciplines:

- Circuit
- Drag
- Drift
- Street X
- URL

Additional improvements include automatic setup recommendations, applying presets to multiple vehicles, manual adjustments, and Undo support.

## 🖼️ Vehicle Previews & Interface

- Added **43 vehicle images** for the expanded vehicle catalog.
- Improved vehicle previews in Career and Arcade / My Cars.
- Added vehicle search and filtering.
- Improved layout and organization of editing tools.
- Refined the NFS Underground 2-inspired interface.
- Simplified performance controls and traffic-car settings.
- Clearer distinction between standard and experimental features.

Three traffic vehicle images are still being completed.

## 🌍 Language Support

Underground Studio now supports:

- **English** (default)
- **German (Deutsch)**

Interface labels, controls, and supported dialogs are available in both languages.

## 💾 Savegame Compatibility & Stability

- Improved savegame import and export.
- ZIP-based savegame handling.
- Improved vehicle record processing and data validation.
- Additional checksum and integrity checks.
- Better protection against invalid garage configurations.
- Improved preservation of existing vehicle data.
- Numerous fixes for vehicle replacement, performance editing, and interface consistency.
